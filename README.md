# AI Career Mentor

An AI-powered career guidance web app that analyzes resumes and user profiles to identify skill gaps and generate personalized interview preparation.

## Features

- 📄 Resume upload with drag-and-drop support
- 🔍 AI-driven skill-gap analysis based on resume content
- 🎯 Personalized interview preparation recommendations
- 🔐 User authentication and session handling
- 📊 Protected dashboard with sidebar navigation

## Tech Stack

**Frontend**
- React
- Vite
- Tailwind CSS v4
- React Router
- Axios
